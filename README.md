# Entropy

**Форум, где посты живут ограниченное время.**

### Я забил на сайт на некоторое время и поэтому на нем есть некоторые баги.
### Сейчас я работаю над другим более серьезным проектом, MintBoard, тоже на Django.
### Возможно через месяца 3 вернусь к нему.

Оригинальный сайт: entropy-zfyh.onrender.com

Посты на Entropy существуют 7 дней, после чего исчезают. Это создаёт
динамичную ленту без вечного мусора - контент либо ценный, либо умирает.

## Фичи

- **⏳ Посты с таймером** - 7 дней жизни. Можно продлить комментариями и лайками.
- **🏆 Золотые посты** - ручные ивенты от администратора. Живут 24 часа,
  лайки и комментарии приносят токены.
- **💎 Экономика** - токены за стрики и квесты, трата на создание постов и темы профиля.
- **🔥 Стрики** - ежедневные награды за регулярные визиты.
- **🎯 Квесты** - 3 случайных задания. Новое — через 3 дня после выполнения.
- **🎨 Темы профиля** - цвета ника, свечение, кастомный стиль.
- **📁 Узлы (Nodes)** - тематические разделы со своими правилами.
- **🪦 Кладбище** - мёртвые посты, только названия.
- **🌙 Тёмная тема** - автоматически, по системе.
- **📱 PWA** - можно установить на телефон как приложение.

## Стек

- Python 3.12+ / Django 5.2
- SQLite (dev) / PostgreSQL (prod)
- Tailwind CSS (via CDN)
- Cloudinary (медиа)
- WhiteNoise (статика)
- Web Push (PWA-уведомления)

## Быстрый старт

```bash
# 1. Клонировать
git clone https://github.com/.../entropy.git
cd entropy

# 2. Окружение
python -m venv venv
source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate   # Windows

# 3. Зависимости
pip install -r requirements.txt

# 4. Настройки
cp .env.example .env
# Отредактировать .env - хотя бы SECRET_KEY

# 5. База данных
python manage.py migrate

# 6. Запуск
python manage.py runserver
```

## Переменные окружения

Все настройки — через `.env`. Смотри `.env.example`.

| Переменная         | Обязательна | Описание                                |
|--------------------|-------------|----------------------------------------|
| `SECRET_KEY`       | ✅          | Ключ Django                            |
| `DEBUG`            | ❌          | `True` для разработки                  |
| `DATABASE_URL`     | ❌          | PostgreSQL URL (по умолчанию SQLite)   |
| `GOD_USERNAME`     | ❌          | Администратор (по умолчанию `admin`)   |
| `CLOUDINARY_*`     | ❌          | Облачное хранилище медиа               |
| `WEBPUSH_VAPID_*`  | ❌          | PWA-уведомления                        |

## Деплой

Проект рассчитан на Render / Railway. Пример `Procfile` уже есть:

```
web: gunicorn entropy.wsgi
```

Не забудь:

1. `python manage.py collectstatic`
2. Установить `DATABASE_URL` в PostgreSQL
3. Прописать `ALLOWED_HOSTS` и `CSRF_TRUSTED_ORIGINS`
