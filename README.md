# Entropy Project

Минималистичный форум с механикой «старения» постов.

## Как запустить локально:
1. Создать окружение: `python -m venv venv`
2. Активировать: `.\venv\Scripts\activate`
3. Установить библиотеки: `pip install -r requirements.txt`
4. Запустить: `python manage.py runserver`

## Основные фишки:
- Система Vitality (жизненная сила постов).
- "Золотые посты" (закрепляются навсегда).
- Кладбище постов.
